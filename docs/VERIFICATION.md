## 最终界面检查

当时检查了 1440×1000、768×1024、390×844 三种尺寸，每种分别有浅/深主题、空/配置后离线两种状态，共 12 张。历史预览图片已清理；后续可按 README 中的命令生成到不纳入版本管理的 `output/previews/`。图中的终端和折线是独立测试工作区，均明确为未连接，没有模拟在线指标。真实应用首次启动为空。

- 主要问题是“当前终端是否在线、如何连接、任务与报文如何检查”。桌面第一屏呈现连接动作、位置、任务及日志；手机使用底部导航和按需展开。
- 统计从控制器计算；零值显示为零，发送记录不等同于平台已确认位置接收。
- 颜色只承担主要动作、选中、路线和连接/错误语义；没有渐变、发光或虚构图表。
- 已修复原生新版本 ListTile 的 Material 绘制层问题、ExpansionTile 与文本滚动的 PageStorage 类型冲突；测试覆盖表单、导入确认和错误恢复。
- 使用已有思源黑体文件作为测试渲染字体以便阅读中文，并加载 Material Icons。字体文件没有复制进应用；原生应用保留系统字体。
- 这些是 Flutter widget 渲染与交互检查，不声称运行了基于 DOM 的 Impeccable/Taste 浏览器检查脚本，也不是所有平台的真机验收。
