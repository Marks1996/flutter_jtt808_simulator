# 中国大陆接入与验收

本项目新工作区默认使用 **天地图官方底图与中文注记 + 高德官方驾车规划**，两项均使用操作者自己的 Key。应用不内置公共 Key，不使用未经授权的高德/百度内部瓦片地址，也不以海外公共演示服务作为新工作区的默认依赖。

应用也提供明确选择的免 Key 公开预设：实测可返回正常图片的 Esri World Imagery 卫星影像、公共 OSRM 和 FOSSGIS OSRM，点击填入后需应用配置；地址仍可编辑，原有 Key 保留。原 OSM 快捷地址因直连超时已替换，手动 OSM 连接仍保留。公开服务与限制、单次直连结果见 [KEYLESS_SERVICES.md](KEYLESS_SERVICES.md)。它们不会在启动或失败时自动启用。

## 配置选项与可空值

| 范围 | 选项 | 输入 |
|---|---|---|
| 底图 | 天地图 | 独立 Key，可空 |
| 底图 | 高德 | 独立底图 Key，可空；高级授权瓦片模板也可暂空 |
| 底图 | 百度 | 独立底图 AK，可空；高级授权瓦片模板也可暂空 |
| 底图 | OSM（免 Key / 自定义） | 手动编辑自己的 HTTPS XYZ 连接，不提供 Key 输入框，可暂空；原标准 OSM 快捷入口已替换为实测影像，避免推荐不可达地址 |
| 底图 | 自定义 XYZ（保留的高级选项） | 模板、坐标系与版权标识，不使用国内图商 Key 字段 |
| 驾车规划 | 高德 | 独立 Web 服务 Key，可空，与高德底图 Key 分开 |
| 驾车规划 | OSRM（免 Key / 自定义） | 可一键填入公共 OSRM 或 FOSSGIS 驾车入口，也可编辑自己的根地址，不提供 Key 输入框，可暂空 |

各来源的地址与 Key 分别保留，切换选项不会互相覆盖。空值可保存、导出和重开；“可空”表示允许处于待配置状态，不代表供应商允许无凭据访问。未配置连接、天地图缺 Key、高德规划缺 Key，或授权模板使用 `{key}` 而对应 Key 为空时，不发送对应请求。

高德、百度底图仍需要允许第三方地图引擎使用的授权地址。若供应商采用查询参数认证，可以填写形如 `https://authorized.example.cn/{z}/{x}/{y}.png?key={key}` 的模板（示例域名不能实际使用）。`{key}` 仅允许出现在高德/百度模板的查询参数中，请求时进行 URL 编码替换，保存和编辑仍保留原占位符；不允许放入主机名或路径。没有该占位符时，程序不会擅自附加新 Key。旧地址内已有的令牌保持原样，单独清空 Key 字段不会删除该地址中原有的令牌，需要操作者自行移除。

旧版已明确选择 OSM 且 JSON 中缺少 `osmUrl` 字段时，迁移保留原公共 OSM 地址。新建 OSM 连接或显式清空的地址不会自动回填公共地址。OSRM 同样不自动填入公共演示服务。

## 首次配置

1. 在 [天地图控制台](https://console.tianditu.gov.cn/api/key)申请适用于地图服务的 Key，核对应用类型、域名/IP 限制、配额和许可。
2. 打开「设置 → 地图底图」，选择「天地图」，填写 Key 并应用。程序自动使用官方 HTTPS `vec_w` 底图和 `cva_w` 中文注记，子域名范围为 `t0`–`t7`，无需手写瓦片模板。
3. 按[高德 Web 服务 Key 指南](https://lbs.amap.com/api/webservice/create-project-and-key)申请具有驾车路径规划权限的 Key。它与天地图 Key、JS Key、移动 SDK Key 不通用。
4. 在「设置 → 路径规划」填写高德 Web 服务 Key，核对用途授权后保存。在「线路与任务 → 新增线路 → 地图建线」选点，点击「规划驾车线路」请求路线。
5. 地图和规划 Key 可单独填写，也可清空并保存。未配置地图 Key 时不请求底图或注记，未配置规划 Key 时不发送规划请求；界面给出设置位置，离线 CSV、坐标轨迹、回放和 JT808 模拟功能仍可使用。

设置页提供两个申请入口。Key 掩码显示，但本机工作区存储和 JSON 导出仍为明文；请勿在公开截图、聊天或共享备份中泄露真实 Key。代码和测试示例中的 `test-key` 等值不是可使用的凭证。

## 网络与坐标

- 默认地图请求仅发送到 `https://t0.tianditu.gov.cn` 至 `https://t7.tianditu.gov.cn`；底图和注记是独立图层、独立瓦片提供器。
- 默认规划请求仅发送到 `https://restapi.amap.com/v5/direction/driving`，仍需操作者明确点击规划。没有自动向其他图商或海外服务重试、回退的逻辑。
- 天地图球面墨卡托图层按 WGS84 经纬度近似显示其地理位置；其数据基准涉及 CGCS2000，不把这种显示近似当作测绘精度保证。高德规划输入/输出采用 GCJ-02，在 API 边界近似转换为 WGS84；存储、CSV、回放和 JT808 上报统一使用 WGS84。
- 超时、权限、配额或加载错误会有提示；底图失败保留离线轨迹，规划失败不生成虚构道路。不要依赖某个公共接口永久可达，也不要把 Key 格式正确当作已通过账号鉴权。
- 高德途经点默认权限通常为 1 个，官方上限为 16 个；需核对自己的账号权限。强制数字签名的账号配置当前不支持。

## 旧工作区

缺少底图或规划字段的旧工作区采用新的国内默认配置；**已有明确保存的图源、地址、Key、开关和路线不自动覆盖**。如果旧工作区仍选择 OSM 或公共 OSRM，需要在设置中明确切换为天地图和高德。

OSM、自定义图源和 OSRM 继续作为可选项。OSRM 默认地址现在留空，使用者可填写国内自建 HTTPS 服务；本机开发可使用 `http://127.0.0.1:5000`。已保存的公共演示地址仍保留并提示大陆可达性和服务稳定性限制。保留旧配置不表示这些海外服务已经通过大陆联网验证。

## 许可

天地图开放地图服务需要自有 Key，并按供应商要求保留版权、审图号和其他必要标识。界面来源文字不能替代全部法定或合同标识。

高德 Key 或底图授权不能单独证明允许本工具的全部用途。使用者需确认第三方底图展示、坐标转换、路线存储/导出、离线回放与 JT808 模拟发送均在许可范围内；配置中的授权确认是操作者声明，不是本项目授予的许可。

## 大陆实网验收清单

本轮组件和协议测试不能代替运营商网络验收。正式使用前，应在目标中国大陆网络、关闭代理/VPN并使用自己的合规 Key 检查：

- 应用从空工作区启动，未配置 Key 时不产生底图或规划请求；配置后默认请求无 OSM/公共 OSRM 域名。
- 典型城区至少两个缩放级别正常显示道路和中文地名，底图/注记均成功返回图片，而非错误 XML/JSON。
- 两个起终点及账号允许数量的途经点可规划，蓝线与地图道路对齐；保存并重开后路线、选点仍在。
- 清空 Key 后不再发送后续新请求；错误 Key、配额不足、断网与超时均有恢复提示。已在途的请求和缓存不会因清空 Key 而被追溯撤销。
- CSV/JSON 与 JT808 报文仍使用 WGS84；切换底图不会修改路线。
- 在实际发布的 macOS/Android/iOS 平台分别验收网络权限、账号 IP/域名限制与必要的供应商标识。

目前未取得真实天地图/高德 Key，也未提供目标大陆运营商网络作为测试条件，因此不能宣称已完成大陆实网验收。

## 官方依据

- [天地图地图服务](https://lbs.tianditu.gov.cn/server/MapService.html)：HTTPS、Key、WMTS、`vec_w`/`cva_w` 和 `t0`–`t7`。
- [高德路径规划 2.0](https://lbs.amap.com/api/webservice/guide/api/newroute)：Web 服务 Key、v5 驾车接口、途经点和返回结构。
- [高德服务条款](https://lbs.amap.com/pages/terms/)及[天地图开放平台](https://lbs.tianditu.gov.cn/)：供应商许可和接入要求以最新官方说明及实际合同为准。
